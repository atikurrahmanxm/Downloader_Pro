# 🎬 Downloader_Pro - Universal Web Video Downloader

যেকোনো ওয়েবসাইট, সোশ্যাল মিডিয়া অথবা স্টক ফুটেজ প্ল্যাটফর্মের লিংক দিলে পেজে থাকা সমস্ত ভিডিও স্বয়ংক্রিয়ভাবে শনাক্ত করে হাই-কোয়ালিটিতে ডাউনলোড করার একটি ফুল-ফিচারড ওয়েব ড্যাশবোর্ড টুল।

---

## ✨ প্রধান সুবিধাসমূহ (Key Features)

1. **মাল্টি-প্ল্যাটফর্ম ডিপ স্ক্র্যাপার (Universal Video Scraper):**
   - **সোশ্যাল মিডিয়া ও স্ট্রিমিং:** YouTube, Facebook, Twitter/X, TikTok, Vimeo, Reddit, Twitch ইত্যাদি ১,৮০০+ প্ল্যাটফর্ম সাপোর্ট করে (`yt-dlp` ইঞ্জিন)।
   - **ফ্রি স্টক ফুটেজ (100% নো-ওয়াটারমার্ক):**
     - **Pexels:** 4K UHD (2160p), 1440p, 1080p Full HD সরাসরি MP4 ডাউনলোড।
     - **Mixkit:** 720p HD ও 360p ফ্রি স্টক ভিডিও।
     - **Pixabay:** 1080p Full HD, 720p HD, 480p ফ্রি স্টক ফুটেজ।
   - **JWPlayer & ওয়েব এম্বেড:** Moviefone ও বিভিন্ন এন্টারটেইনমেন্ট পোর্টালের লুকানো JWPlayer ভিডিও খুঁজে বের করে সরাসরি সিডিএন MP4 ফাইল তৈরি করে।
   - **HTML5 `<video>` & `<iframe>`:** পেজের সব ডিরেক্ট মিডিয়া ও এম্বেডেড প্লেয়ার পার্স করে।

2. **মডার্ন ড্যাশবোর্ড ইন্টারফেস (Modern Glassmorphism UI):**
   - ডার্ক থিম রেসপনসিভ গ্লাস-মরফিজম ডিজাইন (Tailwind CSS)।
   - প্রতিটি ভিডিওর থাম্বনেইল, শিরোনাম এবং ডিউরেশন ডিসপ্লে।
   - **ইন-অ্যাপ ভিডিও প্রিভিউ (Preview):** ডাউনলোড করার আগেই ব্রাউজারে চালিয়ে দেখার ব্যবস্থা।
   - **রেজোলিউশন সিলেক্টর:** 4K, 1080p, 720p, 480p, 360p ইত্যাদি ইচ্ছেমতো বাছাই করার অপশন।
   - **ব্যাচ ডাউনলোড (Download All / Selected):** এক ক্লিকে পেজের সব ভিডিও একসাথে ডাউনলোড।
   - **লাইভ প্রগ্রেস ও স্পিড মিটার:** লাইভ পারসেন্টেজ (%) এবং ডাউনলোড স্পিড (`MB/s`) ট্র্যাকিং।
   - **অটো অডিও-ভিডিও মার্জিং:** ইউটিউবের মতো আলাদা ট্র্যাক থাকা ভিডিওগুলোর ক্ষেত্রে বিল্ট-ইন ffmpeg দিয়ে সাউন্ড ও ভিডিও স্বয়ংক্রিয়ভাবে জোড়া লাগিয়ে ফুল MP4 ফাইল তৈরি।

## 🚀 কীভাবে চালু করবেন (Quick Start)

### সহজ পদ্ধতি (Windows 1-Click):
- ফোল্ডারে থাকা **`Start_Downloader.bat`** ফাইলে ডাবল ক্লিক করুন! 
- স্বয়ংক্রিয়ভাবে সার্ভার চালু হয়ে আপনার ডিফল্ট ব্রাউজারে ড্যাশবোর্ডটি ওপেন হয়ে যাবে (`http://127.0.0.1:5000`)।

### ম্যানুয়াল পদ্ধতি (Terminal / Command Prompt):
```bash
# ১. ডিপেনডেন্সি ইন্সটল করুন (যদি না থাকে)
pip install -r requirements.txt

# ২. সার্ভার রান করুন
python app.py
```
এরপর ব্রাউজারে যান: `http://127.0.0.1:5000`

## 📁 ডাউনলোড করা ফাইল কোথায় জমা হয়?
সমস্ত ডাউনলোড করা ভিডিও স্বয়ংক্রিয়ভাবে প্রোজেক্ট ফোল্ডারের ভেতরে **`downloads/`** ডিরেক্টরিতে সেভ হয়। 
ড্যাশবোর্ডের উপরের ডানদিকের **"Downloads Folder"** বাটনে এক ক্লিক করলেই সরাসরি উইন্ডোজ ফাইল এক্সপ্লোরার ওপেন হয়ে যাবে।

## 🛠️ টেকনোলজি স্ট্যাক (Tech Stack)
- **Backend:** Python 3.10+, Flask
- **Engines:** yt-dlp, curl_cffi, BeautifulSoup4, Playwright, imageio-ffmpeg
- **Frontend:** HTML5, Modern Tailwind CSS, FontAwesome, JavaScript (Vanilla ES6)
