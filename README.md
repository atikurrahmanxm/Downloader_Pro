## 🌟 সারসংক্ষেপ (Overview)

**Downloader Pro** হলো একটি পাওয়ারফুল অল-ইন-ওয়ান ভিডিও ডাউনলোডার সফটওয়্যার। সাধারণ ডাউনলোডারগুলো যেখানে অনেক ওয়েবসাইটে ফেইল করে বা ওয়াটারমার্ক ফেলে দেয়, সেখানে এই সফটওয়্যারটি **7-Tier Deep Inspection Engine** এবং **স্মার্ট মাল্টি-চাংক ডাউনলোডার** ব্যবহার করে। 

এটি ফেসবুক রিলস, ইউটিউব ৪কে, টিকটক নো-ওয়াটারমার্ক, পিক্সেলস ৪কে স্টক ভিডিও, মিক্সকিট, পিক্সাবে এবং জটিল মুভি পোর্টালের লুকানো **JWPlayer / HLS Stream** স্বয়ংক্রিয়ভাবে নিখুঁত ফুল MP4 ফাইলে ডাউনলোড করে সরাসরি আপনার কম্পিউটারে সেভ করে।

## ✨ প্রধান সুবিধাসমূহ (Key Features)

### 1. 🎯 ইউনিভার্সাল 7-Tier ডিপ স্ক্র্যাপার ইঞ্জিন
- **সোশ্যাল মিডিয়া ও স্ট্রিমিং:** YouTube, Facebook Reels/Watch, Instagram Reels/Posts, TikTok (No Watermark), Twitter/X, Vimeo, Reddit, Twitch ইত্যাদি ১,৮০০+ সাইট সাপোর্ট করে।
- **ফ্রি স্টক ফুটেজ এক্সট্র্যাক্টর (100% নো-ওয়াটারমার্ক):**
  - **Pexels:** 4K UHD (2160p), 1440p, 1080p Full HD অরিজিনাল MP4।
  - **Mixkit:** 720p HD ও 360p ডিরেক্ট ফ্রি স্টক ফাইল।
  - **Pixabay:** 1080p FHD ও 720p ক্রিস্টাল ক্লিয়ার ফুটেজ।
- **JWPlayer & ওয়েব এম্বেড ডিকোডার:** Moviefone ও বিভিন্ন এন্টারটেইনমেন্ট পোর্টালের সুরক্ষিত JWPlayer API ডিকোড করে সরাসরি হাই-স্পিড CDN MP4 ফাইল তৈরি করে।
- **Playwright হেডলেস ব্রাউজার স্নাইফার:** ডাইনামিক সিঙ্গেল-পেজ অ্যাপ ও জাভাস্ক্রিপ্ট প্লেয়ারের ক্ষেত্রে ব্যাকগ্রাউন্ডে ব্রাউজার খুলে নেটওয়ার্ক ট্রাফিক থেকে লাইভ মিডিয়া স্নাইফ করে।

### 2. 💎 আধুনিক প্রিমিয়াম গ্লাস-মরফিজম ড্যাশবোর্ড
- **মডার্ন ডার্ক থিম:** Tailwind CSS ও Plus Jakarta Sans টাইপোগ্রাফি দিয়ে তৈরি আরামদায়ক ও চোখ ধাঁধানো ইন্টারফেস।
- **ইনপুট ক্লিয়ার ও পেস্ট বাটন:** এক ক্লিকে ক্লিপবোর্ড থেকে লিংক পেস্ট (`📋 Paste`) এবং ইনপুট মুছে ফেলার জন্য স্মার্ট `✕` বাটন।
- **ব্র্যান্ড প্ল্যাটফর্ম পিলস:** কোন কোন সাইট সাপোর্টেড তা এক নজরে দেখার জন্য টিকার।
- **রেজোলিউশন ও ফরম্যাট সিলেক্টর:** 4K UHD, 1080p FHD, 720p HD, SD এবং অডিও প্রেমীদের জন্য **🎵 Audio (MP3)** অপশন।
- **ইন-অ্যাপ ভিডিও প্রিভিউ (Preview):** ডাউনলোড না করেই ব্রাউজারের ইন-বিল্ট প্লেয়ারে ভিডিওটি চালিয়ে দেখে নেওয়ার সুযোগ।

### 3. ⚡ জিরো-হ্যাং ও সুপারফাস্ট ডাউনলোডার
- **স্মার্ট স্ট্রিম রাউটার:** সরাসরি MP4 ফাইলগুলো মাল্টি-চাংক HTTP স্ট্রিমিংয়ে ডাউনলোড হয় (ফেসবুক বা কোনো সাইট বট ব্লক দেওয়ার সুযোগ পায় না)।
- **লাইভ প্রগ্রেস ও স্পিড মিটার:** লাইভ পার্সেন্টেজ (`%`), ডাউনলোড স্পিড (`MB/s`) এবং সাইজ কাউন্টার (`34.5 MB / 80.2 MB`)।
- **অটো অডিও-ভিডিও মার্জিং:** ইউটিউবের মতো আলাদা ভিডিও ও অডিও ট্র্যাক থাকা স্ট্রিমে বিল্ট-ইন `FFmpeg` ইঞ্জিন স্বয়ংক্রিয়ভাবে মার্জ করে দেয়।

### 4. 🎬 ১-ক্লিক ইনস্ট্যান্ট ভিডিও প্লে ও এক্সপ্লোরার
- কোনো ভিডিও ডাউনলোড সম্পন্ন হওয়ামাত্র ড্যাশবোর্ডে **"Play"** বাটনে এক ক্লিক করলেই ফাইলটি সরাসরি আপনার উইন্ডোজের ডিফল্ট মিডিয়া প্লেয়ারে (VLC, Windows Media Player) চালু হয়ে যাবে!
- **"Downloads Folder"** বাটনে ক্লিক করলেই সরাসরি উইন্ডোজ এক্সপ্লোরারে সেভ হওয়া ফোল্ডারটি ওপেন হবে।

## 🚀 কীভাবে চালু করবেন (Quick Start)

### পদ্ধতি ১: সহজ ১-ক্লিক চালু (Windows Recommended) ⚡
1. এই প্রোজেক্ট ফোল্ডারে থাকা **`Start_Downloader.bat`** ফাইলে ডাবল ক্লিক করুন।
2. সার্ভার স্বয়ংক্রিয়ভাবে চালু হয়ে আপনার পছন্দের ব্রাউজারে ড্যাশবোর্ডটি ওপেন করে দেবে:  
   👉 **`http://127.0.0.1:5000`**

---

### পদ্ধতি ২: টার্মিনাল / কমান্ড প্রম্পট দিয়ে ম্যানুয়াল রান ⌨️

```bash
# ১. রিপোজিটরি ক্লোন করুন (অথবা ফোল্ডারে প্রবেশ করুন)
cd "Downloader_Pro"

# ২. পাইথন লাইব্রেরিসমূহ ইন্সটল করুন
pip install -r requirements.txt

# ৩. (ঐচ্ছিক) প্লে-রাইট হেডলেস ব্রাউজার সাপোর্ট সচল করতে রান করুন
playwright install chromium

# ৪. অ্যাপ্লিকেশন রান করুন
python app.py
```
সার্ভার চালু হলে ব্রাউজারে যান: `http://127.0.0.1:5000`

---

### পদ্ধতি ৩: ১-ক্লিকে GitHub এ আপডেট ও পুশ করা 🚀
ভবিষ্যতে যেকোনো আপডেট গিটহাবে আপলোড করতে ফোল্ডারে থাকা **`Push_To_GitHub.bat`** ফাইলে ডাবল ক্লিক করলেই কোড স্বয়ংক্রিয়ভাবে আপনার রিপোজিটরিতে পুশ হয়ে যাবে:

## ⚙️ 7-Tier ডিপ স্ক্র্যাপার আর্কিটেকচার

```
[ ইউজার পেস্ট করা URL ]
          │
          ├──► Tier 1: ডিরেক্ট মিডিয়া ফাইল ডিটেকশন (.mp4, .webm, .m3u8, .mov)
          │
          ├──► Tier 2: শর্ট লিংক রিডাইরেক্ট রেজলভার (fb.watch, vt.tiktok, youtu.be)
          │
          ├──► Tier 3: ডেডিকেটেড স্টক ফুটেজ এক্সট্র্যাক্টর (Pexels 4K, Mixkit, Pixabay)
          │
          ├──► Tier 4: সোশ্যাল মিডিয়া স্পেশালাইজড স্ক্র্যাপার (Facebook & Pinterest Fallbacks)
          │
          ├──► Tier 5: JWPlayer CDN রেজলভার (Moviefone & Video Portals)
          │
          ├──► Tier 6: yt-dlp ইউনিভার্সাল ইঞ্জিন (সোশ্যাল ও স্ট্রিমিং ১,৮০০+ সাইট)
          │
          ├──► Tier 7: ডিপ HTML5, JSON-LD স্কিমা, OpenGraph ও স্ক্রিপ্ট রেজেক্স পার্সার
          │
          └──► Fallback Tier: Playwright হেডলেস ব্রাউজার নেটওয়ার্ক স্নাইফার (JS Players)
```

## 🛠️ টেকনোলজি স্ট্যাক (Tech Stack)

- **Backend:** Python 3.10+, Flask Framework
- **Core Extractors:** yt-dlp, curl_cffi, BeautifulSoup4, Playwright Sync API
- **Audio/Video Engine:** imageio-ffmpeg (Built-in static FFmpeg binary)
- **Frontend Dashboard:** HTML5, Modern Tailwind CSS, FontAwesome 6, Vanilla ES6 JavaScript
- **Version Control:** Git, GitHub
